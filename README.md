
# AttendX Test Scripts

## Project Description
This repository contains sample automation test scripts for
the AttendX student attendance application.

## Test Scripts

### 1. test_login.py
- Tests login with valid credentials.
- Tests login with empty credentials.

### 2. test_mark_attendance.py
- Tests marking attendance for a student.
- Tests attendance submission without a student ID.

## Technologies Used
- Git
- GitHub
- Visual Studio Code
- Python

## Purpose
To maintain test scripts using version control and enable
QA engineers to collaborate without overwriting each other's work.

## Note
These scripts simulate application behavior and are examples
for the version-control practical. They are not integrated
with a live AttendX application.
